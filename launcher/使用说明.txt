# DeepSeek Harness 桌面版 · 零基础使用说明

本包包含一个桌面版程序和一个一键启动器，面向第一次使用的新用户。
适用系统：Windows 10 / Windows 11（64 位）。

---

## 一、快速开始（三步）

1. **双击 `启动.bat`** —— 启动器会自动完成全部准备工作：
   - 检查并安装 Node.js（如缺失）
   - 检查并安装 DeepSeek Harness 命令行工具（如缺失）
   - 引导你注册 DeepSeek 平台账号、创建并填入 API Key
   - 验证本地环境可正常启动
   - 在桌面创建快捷方式
2. **按提示操作** —— 全程中文提示，跟着走即可；需要粘贴 API Key 时，
   浏览器会先打开 DeepSeek 开放平台（https://platform.deepseek.com），
   注册/登录后到「API Keys」页面创建并复制 key（形如 sk-xxxxx）。
3. **双击桌面上的「DeepSeek Harness 桌面版」** 或再次运行 `启动.bat`，
   等待窗口出现即可开始使用。

---

## 二、本包内容

| 文件 | 作用 |
| --- | --- |
| `启动.bat` | 一键启动器入口（双击它） |
| `launcher.ps1` | 启动器主体（自动检查/安装/配置） |
| `创建桌面快捷方式.bat` | 只想在桌面放快捷方式时使用 |
| `*-portable.exe` | 桌面版程序本体（便携版，无需安装） |

## 三、常见问题

**Q: 启动时提示未找到 Node.js？**
A: 启动器会自动帮你安装。若自动安装失败，可手动到
https://nodejs.org/zh-cn/download 下载 LTS 版安装后重试。

**Q: 在哪里管理我的 API Key？**
A: 保存位置：`C:\Users\<你的用户名>\.dsh\.credentials.yaml`
（文件内容形如 `DEEPSEEK_API_KEY: sk-xxxxx`，请勿外泄）。
重新运行 `启动.bat` 可重新配置。

**Q: 双击快捷方式没反应或白屏？**
A: 首次启动需要 10-30 秒等待服务就绪，请稍候。
若长时间无反应，运行 `启动.bat` 查看自检结果。

**Q: 日志在哪？**
A: `%APPDATA%\dsh-desktop\logs\` 目录下，文件名带时间戳。

## 四、环境要求（自动检查）

- Windows 10/11 x64
- Node.js >= 20（缺失时启动器自动安装）
- 网络可用（安装组件、使用 AI 均需联网）
